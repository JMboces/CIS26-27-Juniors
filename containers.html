html containers

container

any element with an opening or closing tag that holdss content.

<div>

generic block container with no meaning of its own. this tag is useless without a class or id attribute

<span>

generic inline container with no meaning of its own this tag is useless without a class or id attribute

block vs inline

a block container - starts on a new line and stretches across its parent container's full width. an inline container stays in the flow of the line and takes as much room as its content
