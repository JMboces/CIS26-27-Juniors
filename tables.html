the table element

<table > - this is the element that creates and html table html tables are used to organize data into rows and columns.

Cell

<cell> - it is a location in the table at a specific row and column. cells are created at the intersection of a row and column.

table row

<tr> - this is the element that creates a row in the table. table rows are nested inside of table elements.

table header

<th> - the element that creates a cell containing the table header information about the data contained in a specific column. table header cells are nested inside of table rows.

data cell /table

<td> - the element that creates a cell containing the main data for the table. data cells are nested inside of table rows.

caption

<caption> - the element that creates a caption for the table. captions are nested inside of table elements.
